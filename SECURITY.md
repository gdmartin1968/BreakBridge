# Security Policy

## Supported Versions

BreakBridge is currently in active development and transitioning from prototype to production architecture.

At this time:
- Only the latest version on the `main` branch is considered supported
- Earlier commits and prototype implementations are not maintained for security updates

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

You may:
- Open a private issue (if appropriate), or
- Contact directly via GitHub profile

Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Potential impact

## Scope & Notes

BreakBridge is an operational decision-support platform for childcare staffing.

To protect system integrity:
- Certain implementation details are intentionally abstracted or omitted from the public repository
- No real customer or childcare data is included in this repository

Security and data integrity are treated as core system requirements and will continue to be strengthened as the platform evolves.
